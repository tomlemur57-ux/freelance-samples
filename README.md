# Tom Vu — small technical demos

This public-facing demo repository contains small, runnable portfolio examples by Tom Vu (`tomlemur57-ux`). All rows, dashboard values and form data are synthetic. They are demonstrations of the workflow, not client deliverables.

## Demos

- [`csv-report`](csv-report/): Python standard-library CSV validation, duplicate handling, deterministic sorting, and a JSON summary. Run the included unit tests with `python -m unittest -v` from that directory.
- [`layout-fix`](layout-fix/): a self-contained HTML/CSS/JavaScript responsive layout sample. Open `index.html` in a browser and use the button to compare the original and corrected grid rules. `browser-checks.json` records the reviewed viewport observations.
- [`fillable-pdf`](fillable-pdf/): an interactive one-page project brief with text fields, a dropdown and a checkbox. Includes the PDF and its small generation script.
- [`tutorial-carousel`](tutorial-carousel/): a four-slide ChatGPT + Python tutorial design with editable SVG sources and verified synthetic CSV results.
